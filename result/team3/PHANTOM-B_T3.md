# PHANTOM-B
## 内部にAI機能を有するアプリケーション
### 9つの問い
| | 問い | 脅威 |
| ---- | ---- | ---- |
| P | どうすればプロンプトインジェクションが可能か? | LLMでないため対象外 |
| H | ハルシネーションが想定を超えたらどうなるか? | 誤検知が多く品質問題が発生する |
| A | LLMを擬人化していないか? | LLMでないため対象外 |
| N | いつ、誰に対して、出力を説明・正当化する必要があるか? | もし不良品が原因でクレームが発生した場合に、取引先に対してなぜ良品と判断したかの説明をする必要がある |
| T | 学習データに偶発的または意図的な品質問題があったらどうなるか? | 学習データに良品のデータが多く、不良品を検知できない |
| O | LLMはどのような判断を行い、何に対してどのような制御権を持っているか。それにより意図せず攻撃面が拡大していないか?(「エージェント型AI」のデプロイパターンでは特に重要) | 検知機構に過度に依存してしまうことで生産ラインに影響を及ぼす |
| M | 脅威モデリングを含め、SDL(セキュア開発ライフサイクル)のその他のセキュリティエンジニアリングを適切に実施したか? | - |
| - | LLMがアクセスできるデータ、および情報が開示され得る先を制御できているか? | LLMでないため対象外 |
| B | LLMにはどのようなバイアスがあり、それはこのユースケースにおいて許容できるか? | LLMでないため対象外 |

## 外部のLLMを用いたアプリケーション
### 9つの問い
| | 問い | 脅威 |
| ---- | ---- | ---- |
| P | どうすればプロンプトインジェクションが可能か? | 会話の文字起こしにプロンプトインジェクションが含まれる |
| H | ハルシネーションが想定を超えたらどうなるか? | 議事録の重要な決定事項に誤りがあり、経営判断を誤る |
| A | LLMを擬人化していないか? | 議事録の内容に間違いがないことを期待してしまう |
| N | いつ、誰に対して、出力を説明・正当化する必要があるか? | 議事録を見た人に、なぜそのように要約しているかの説明ができない |
| T | 学習データに偶発的または意図的な品質問題があったらどうなるか? | カットオフの問題で最近の言葉を含む内容を正しく要約できない。また、最新の法改正を考慮した要約ができない |
| O | LLMはどのような判断を行い、何に対してどのような制御権を持っているか。それにより意図せず攻撃面が拡大していないか?(「エージェント型AI」のデプロイパターンでは特に重要) | 議事録の内容に疑いを持たず経営判断を誤る |
| M | 脅威モデリングを含め、SDL(セキュア開発ライフサイクル)のその他のセキュリティエンジニアリングを適切に実施したか? | - |
| - | LLMがアクセスできるデータ、および情報が開示され得る先を制御できているか? | 会話の文字起こしに含まれる顧客の個人情報がLLMに入力される |
| B | LLMにはどのようなバイアスがあり、それはこのユースケースにおいて許容できるか? | 曖昧な表現に対してもポジティブに要約されてしまう |

## エージェント型AIを用いたアプリケーション
### 9つの問い
| | 問い | 脅威 |
| ---- | ---- | ---- |
| P | どうすればプロンプトインジェクションが可能か? | 3rd PartyのAPIが返す応答にプロンプトインジェクションが含まれており、想定外のホテルが予約される |
| H | ハルシネーションが想定を超えたらどうなるか? | 存在しないホテル、予算外のホテルが予約される。他人名義でホテルが予約される |
| A | LLMを擬人化していないか? | その人に適さないプランが予約される(例:これまで禁煙室を予約していたのに喫煙室が予約される) |
| N | いつ、誰に対して、出力を説明・正当化する必要があるか? | ホテル予約をした人からの問い合わせに対して、なぜこのホテルを予約したかの説明ができない |
| T | 学習データに偶発的または意図的な品質問題があったらどうなるか? | モデルに問題があってホテルが予約できない。モデルのカットオフが古く、新しく開業したホテルを予約できない |
| O | LLMはどのような判断を行い、何に対してどのような制御権を持っているか。それにより意図せず攻撃面が拡大していないか?(「エージェント型AI」のデプロイパターンでは特に重要) | 予約変更ができないホテルについて予約確定を人が確認せず、キャンセル料がかかる |
| M | 脅威モデリングを含め、SDL(セキュア開発ライフサイクル)のその他のセキュリティエンジニアリングを適切に実施したか? | - |
| - | LLMがアクセスできるデータ、および情報が開示され得る先を制御できているか? | 顧客の予約のために必要な個人情報がLLMに入力される |
| B | LLMにはどのようなバイアスがあり、それはこのユースケースにおいて許容できるか? | 推奨ホテルが高級なものに偏る |
